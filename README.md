# 残響アパート — ECHO APARTMENT

一款完全在浏览器中运行的 **日式心理恐怖第一人称探索游戏**（Three.js / WebGL）。
无任何外部素材：所有贴图、音效、模型均在运行时程序化生成，加载即玩。

> 深夜，你在一栋废弃公寓的玄关醒来。
> 3 号室的一家四口在三年前失踪——只有长男下落不明。
> 走廊的尽头有什么在等着你。找到散落的 3 份手记，逃出去。

---

## 快速开始

```bash
cd echo-apartment
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

（ES Modules 需要 HTTP 服务；也可以使用任意静态服务器，如 `npx serve`。）

或者一键测试（无头环境验证关卡与 AI）：

```bash
npm test        # node smoke.mjs
```

## 操作

| 按键 | 功能 |
| --- | --- |
| `W A S D` | 移动 |
| 鼠标 | 视角（指针锁定） |
| `SHIFT` | 奔跑 |
| `F` | 手电筒开关 |
| `E` | 调查 / 开门 / 阅读 |
| `ESC` | 暂停 |
| `R` | 重新开始 |

> **触控板玩家**：macOS 触控板（轻点即点击）可能拿不到指针锁定权限。
> 视角转不动时，**按住鼠标/触控板并拖动**即可转向（游戏内也会弹出提示）。

### 手机 / 平板触屏

手机浏览器打开即自动进入触屏模式（也可用 `?touch=1` 强制开启）：

- **左下虚拟摇杆**：移动（轻推慢走、推满奔跑前速度，模拟量）
- **屏幕其余区域滑动**：转视角
- **右下按钮**：调查（有可交互物时会发光）/ 手电 / 奔跑（按住）
- **右上 ❚❚**：暂停；竖屏时会提示横屏体验更佳
- 视角灵敏度同样可在暂停页调节；建议横屏 + 戴耳机游玩

## 游戏流程

1. 在公寓中寻找 **3 份手记**（寝室的手记、佛间的报纸、儿童房的画）。
2. 第 3 份到手后，全楼熄灯，**怪物开始追击**——二楼的「通往外界的门」会解锁。
3. 逃出去。被抓住会「在玄关醒来」，进度保留。

> 所有字幕、纸条与界面均为 **中文为主、日文为辅** 的双语显示。

## 特色

- **PS1/PS2 复古画面**：640×360 低分辨率渲染 + 像素放大、顶点抖动（vertex snapping）、
  有序抖动（Bayer dithering）、扫描线、胶片颗粒、**内置着色器 Bloom 泛光**、ACES 色调映射；
  贴图使用 Linear 放大 + 三线性 mipmap + 各向异性 16（消除摩尔纹与视角蠕动）。
- **异常空间结构**：超过建筑比例的长走廊、变宽的走廊段、升高的地板段、
  通往砖墙的「死门」（门后是一整面凝视的眼睛）、二楼的环状结构（东楼梯上 → 天桥 → 西楼梯下 → 回到玄关）。
- **隐藏区域**：卧室衣柜后有一条通往浴室的暗道。
- **动态光照**：冷蓝绿荧光灯（真实状态机故障闪烁/熄灭，灯管随光熄灭）、
  带金属灯槽与端盖的吸顶灯具、手电筒（体积光锥 + 每帧跟随相机照射、
  靠近怪物时高频闪烁）、烛火、电视雪花冷光、月光窗（雨痕玻璃）、浴室红色热水器灯、落地灯（可开关，灯罩会亮）；
  **墙上电灯开关真的能用**——每个开关接线到具体灯具，关灯后灯可能自己再亮起来；
  全局体积雾 + 灰尘粒子 + 烘焙式顶点 AO + **雷雨夜闪电**（窗户与天光连闪，雷声延迟到达）。
- **细致场景建模**：全屋踢脚线、走廊墙裙/顶角线、天花板横梁、裸露锈蚀管道（会滴水）、带立柱的楼梯扶手、
  暖气片、停摆的挂钟、玄关信箱（3 号室铭牌模糊不清）与伞架；
  厨房水槽/灶台/油烟机/瓶罐/防溅瓷砖/悬挂锅具、客厅沙发（坐垫+靠垫+毛毯）/书架/地毯/挂画/收音机、
  卧室蒲团寝具（枕头×2+叠被）与穿衣镜、浴室瓷砖墙裙/马桶/洗手台/药品柜、
  儿童房婴儿床/纸鹤风铃/泰迪熊/小桌椅/蜡笔/身高记录墙、佛间坐垫/供品/挂轴。
- **怪物「あの子」**：低多边形、比例异常（2.3m 高、手臂过膝、指骨过长）、空洞眼窝、
  追击时**下颌张开、双目赤红发光**、背部脊突与垂挂的布条；在视线外瞬移逼近，
  被手电筒照射时高频闪烁。
- **环境叙事与随机恐怖事件**：电话铃、门自己开合、灯光逐盏熄灭、幽灵少女、
  身后的脚步声与呼吸声、敲门声、楼上脚步、孩子的哭声、远处孩子的轻笑、
  收音机自响、电视雪花中浮现人脸、窗外的人影、**会自己换位置的人偶**、
  镜子里站在你身后的人、自动打开的橱柜……
- **程序化音效与生成式配乐**（WebAudio）：程序化卷积混响（暗色衰减尾部）、
  环境低音 drone + 随恐惧度加密的稀疏小调动机（**生成式 BGM**）、
  追击时的低音脉冲与不协和音簇、儿童房八音盒摇篮曲、夜风与雨声底噪（楼梯间/二楼更强）、
  距离衰减的雷声、荧光灯嗡鸣、心跳、低语、门轴吱呀、重击、跳吓轰鸣、
  哭声、滴水、金属刮擦，以及**按地面材质区分的脚步声**（木地板/榻榻米/混凝土）。

## 技术结构

```
echo-apartment/
├── index.html          UI/HUD/标题/暂停/结局界面 + import map
├── js/
│   ├── game.js         主循环：渲染、后期、玩家控制、交互、事件导演、惊吓
│   ├── level.js        关卡：几何、碰撞、门、灯光、道具、触发区
│   ├── monster.js      低多边形怪物 + 幽灵少女（程序化模型与动画）
│   ├── textures.js     36 张程序化复古贴图（Canvas 生成）
│   ├── audio.js        WebAudio 程序化音效引擎
│   └── util.js         RNG、AABB 碰撞（含跨台阶/防吸附/防隧穿）、PS1 顶点抖动
├── vendor/             Three.js r160（本地化，离线可用）
├── smoke.mjs           无头冒烟测试（关卡构建 + 怪物 AI + 全图走通）
└── package.json
```

- **零外部资源**：模型、贴图、音频全部代码生成，首屏无网络请求。
- **性能**：约 800 个网格 + 43 盏点光源；**已完全关闭阴影贴图**（PS1 风格不需要，
  同时根除墙面阴影痤疮白斑），明暗靠灯光衰减、烘焙式顶点 AO 与后期泛光表现。
  内部渲染分辨率 640×360，现代 PC 浏览器 60fps 无压力。
- **灯光物理**：所有点光源按 1/d^1.8 衰减并整体压低强度（走廊 2.4 / 房间 1.6-2.0，
  toneMappingExposure 1.38），灯具自带金属灯槽遮挡近场；手电筒带「近墙软衰减」，
  贴墙时自动降低强度，墙面/天花板不再出现大片过曝白斑；
  亮度层级为「荧光灯=氛围、手电筒=主照明」。
- **走廊尺度**：房间段走廊内宽 2.2m；长走廊段（z 32..58）内宽 **2.8m**，减少压迫感。
- **碰撞**：AABB 轴分离解算，支持自动跨台阶（≤0.35m）、
  只处理真正穿入的轴向钳制（贴墙滑行自然）、下落防隧穿；
  落地窗口按「本帧实际下落跨度」锚定，悬浮角色（台阶边缘/传送落地）不会穿地。
  回归：8 方向全高阻挡物冲刺压力测试，**零真实穿透**。
- **交互**：射线调查带墙体遮挡检测，不能隔着墙开门/读手记。

## 回归 / 调试工具

以下 URL 参数仅供开发与回归验证，正常游玩无需使用（对游玩零影响）：

| 参数 | 作用 |
| --- | --- |
| `?autostart=1` | 跳过标题画面直接开始（无头截图用） |
| `?nopost=1` | 绕过后期处理链直接渲染（排查后期问题） |
| `?tp=Z&face=n\|s` | 传送玩家到走廊 z=Z 并凝视北/南墙（确定性截图，从脚下最高地板 0.9m 高处自然落地，支持二楼） |
| `?noflash=1` | 手电筒关闭启动（配合 tp 做白斑 A/B 判别） |
| `?pos=1` | 每 30 帧把玩家坐标写入页面标题（`--dump-dom` 可读） |
