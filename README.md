# 回声公寓 · ECHO APARTMENT

一个在浏览器中运行的日式心理恐怖调查游戏，使用本地 Three.js r160、WebGL 和 WebAudio。模型、贴图与声音在运行时生成，游戏运行不依赖 CDN 或素材服务。

拆除前一夜，你收到一封没有署名的失物招领函，回到曾经住过的公寓。信里叫你「哥哥」，你却不记得那个孩子。停在 02:17 的钟、地下排水间的敲门声和一盘录音，把那一夜重新拼了起来。

4.1 社区调查版包含六章调查、28 份记录、物品与解谜推进、两个结局。恢复供电后，大厅外门连接 48×36 米的社区：中庭、杂货店、卫生站和带雨棚的回路。卫生站的接线记录解释当年的救援为何被取消，并接入既有电台主线。地图包含 B1、1F、2F 和屋顶；保留二楼约 630 平方米西翼，地下新增建筑范围约 1,216 平方米的旧区，包含七个区域和两条可返回的回路。照片背后的钥匙把调查引向未发出的救援呼叫，柴油机和应急电台成为排水前的主线步骤。GitHub Pages 从 `main` 根目录自动发布，推送后的线上更新以 Pages 构建结果为准。

当前分支的迭代与核验边界见 [开发记录](docs/NIGHT-ITERATION.md)。本轮自动化测试已覆盖新路线和剧情；浏览器画面、音频与手机真机体验仍待核验，下方 v4 浏览器记录不能当作本轮画面验收。

## 运行与构建

```bash
npm start
# 打开 http://127.0.0.1:8000
```

项目已包含构建产物，启动预览不需要安装依赖。修改 JavaScript 后再构建：

```bash
npm run build
npm run build:desktop
npm test
npm run audit
```

构建使用 `npm exec` 调用原锁文件中的 `esbuild@0.25.12`；首次构建需要 npm 网络或已有缓存。`index.html` 使用 `js/bundle.js`，`bundle-desktop.js` 是相同游戏的桌面打包入口。两种构建都使用同一份剧情，不会申请摄像头权限。

## 操作

| 操作 | 功能 |
| --- | --- |
| `W A S D` / 方向键 | 移动 |
| 鼠标 / 按住拖动 | 视角；指针锁定不可用时可拖动 |
| `Shift` | 奔跑 |
| `E` | 调查、开关门、阅读、操作谜题；关闭当前调查界面 |
| `F` | 手电开关；耗尽时使用已拾取的备用电池 |
| `J` / `Tab` | 调查手册、随身物品、线索 |
| `M` | 当前楼层平面图，可切换 B1、1F、2F、屋顶 |
| `Esc` | 暂停、音量、亮度、视角灵敏度、减少闪烁与晃动 |
| `R` | 回到最近剧情检查点，保留物品和线索 |

手机和平板自动显示摇杆与触控按钮，也可用 `?touch=1` 强制开启。竖屏使用旋转舞台适配横屏布局。调查界面与暂停会停止移动、追逐、耗电和主线计时。

## 场景与动线

入口大厅连接一楼住户走廊，原来的走廊地洞、陡梯、二楼跨井窄桥已移除。一、二楼都有连续的走廊地板，主楼梯位于走廊尽头的独立楼梯间，连接一楼、二楼和屋顶。采用普通公寓的双跑折返梯：每跑 8 级、升高半层，在实心平台转向。楼层平台与走廊直接接合，沿原路可上下返回。

| 楼层 | 可探索区域 | 剧情与用途 |
| --- | --- | --- |
| B1 | 维修折返楼梯、配电间、排水间 | 恢复供电，处理当年的排水故障 |
| B1 旧区 | 连廊、检修走廊、值班站、发电机房、搬迁档案库、蓄水池、电台室 | 输出熔断器、柴油机启动、救援呼叫，补齐事故责任与孩子等待的故事 |
| 1F | 大厅、厨房、客厅、寝室、浴室、佛间、儿童房 | 来信、熔断器、事故报道、童年记忆、八音盒 |
| 社区 | 中庭、雨夜杂货店、街区卫生站、雨棚连廊 | 面包订单、电话底单、救援接线记录；六扇房门构成可返回的回路 |
| 1F 东翼 | 洗衣房、104 空屋、管理员维修室 | 住户证言、躲藏提示、维修工单、排水阀手轮 |
| 2F | 201 管理室、202 留守住户、203 放映室、露天天井 | 档案密码、录音带、完整真相和出口 |
| 2F 西翼 | 封闭走廊、204 摄影师旧居、暗房、住户纪念室 | 底片、显影液、全家福，补全事故证据 |
| 屋顶 | 晾晒场、长椅、远处楼群 | 母亲的便条、补给，拓展家庭故事 |

楼梯采用连续混凝土梯板、平台梁柱、防滑鼻口、扶手底板和螺栓。家具增加微倒角、木纹与凹凸材质、抽屉把手，门扇有嵌线、锁座和铰链。洗衣机包含橡胶密封圈、金属滚筒、孔眼、玻璃门和控制面板；灯具包含端盖、格栅与紧固件。楼梯间补齐墙裙、踢脚线、接线管、电箱和剥落水痕。

地下旧区增加实体柴油机、散热格栅、仪表、排气管、档案架、维修盒、电台和蓄水池护栏。蓄水池保留完整承重地板，抬高的设备座与水面用于表现场景；护栏有实际碰撞。客厅与右侧儿童房补齐外墙，屋顶楼梯口两侧补齐地板与封边。运动按最大 0.18m 的位移分段解算，防止低帧率时越过薄墙；打开的门仍有门扇碰撞，关门碰到玩家会重新打开。异常掉落恢复到最近有地板、无嵌墙的落脚点，保留剧情进度。

画面以 1280 像素宽为渲染基准，高度随视口比例变化，并根据帧率调整分辨率。参考图的尺寸与连接关系先由实际模型验证，再生成材质参考；提示词与取舍记录见 [建模参考](assets/references/README.md)。这些参考图不作为游戏背景贴图加载。

## 剧情流程

以下内容包含谜题答案。

1. 在大厅值班台读来信，获得维修门钥匙；从厨房工具盒取备用熔断器。
2. 从一楼维修门进入独立折返梯，下到 B1。阅读检修卡，按 **排水 → 走廊 → 住户** 恢复备用电源。
3. 调查佛间剪报，根据停电时刻 **0217** 打开二楼 201 管理室档案柜。
4. 在 202 取录音带，到 203 播放；203 的认领书揭示完整真相。
5. 回到儿童房，按画上的 **Ⅲ → Ⅰ → Ⅳ** 弹奏八音盒，读夹层里的信，取得西翼钥匙。
6. 打开二楼靠近楼梯间的西翼门，在 204 相机旁取底片，从 204 北门进入纪念室取显影液。
7. 到暗房读冲洗规程，按 **显影 → 停显 → 定影 → 水洗** 洗出全家福，找回被遗忘的名字。错误操作保留底片和药液；正确冲洗后照片可在手册里复查。
8. 用相纸夹层里的钥匙打开 B1 配电间最里面的旧区门。读值班日志与搬迁总账，从档案库绿色维修盒取输出熔断器。
9. 到旧区发电机房，按 **预热 → 供油 → 输出** 启动柴油机。错误操作不消耗熔断器；成功后电台备用供电恢复。
10. 从大厅外门进入社区，到右侧卫生站前台读救援接线记录；杂货店的订单与电话底单补齐家庭线索。
11. 回到最里面的应急电台室，读频道表，输入 **1407**，发出求救并接通远端继电器。蓄水池刻字补全孩子等待的经过。
12. 到一楼东翼维修室取排水阀手轮，返回原地下排水间，按 **泄压 → 排水 → 回水** 操作水闸。
13. 天井防火门解锁，追逐开始。抵达二楼天井后选择结局；读过认领书可选择带苍太回家，也可以再次离开。

被追逐时可奔跑、关门、利用衣柜躲藏；不要在怪物眼前躲进去。怪物的观察与攻击受墙体、门和楼层遮挡限制，上下楼沿踏步和中间平台折返。被抓后恢复到最近的剧情检查点，已取得的进度保留。

录音带有 32 秒字幕与程序化音效演出，也可收起查看完整转写。西翼、暗房、纪念室、地下旧区、值班站、蓄水池、电台和再次登上屋顶的区域演出只触发一次。设备使用 HRTF 空间声音，墙体与关门会衰减并滤掉高频；地下、室内与屋顶使用不同混响。柴油机运转声只在启动后出现。

原公寓材质增加凹凸与粗糙度。新场景包含空心冲洗托盘、相机镜头、卷片器、曲面窗帘、晾晒相纸和接触阴影；怪物头部、关节与躯干使用更平滑的曲面，湿发使用曲线发束。

调查与重要谜题会保存到浏览器 `localStorage`。标题页可以继续未完成的调查；新游戏从大厅开始。存档属于当前浏览器和站点。保留 v2 存档键和外层 `version`，当前 `revision=5`。尚未排水的 2.0 / 3.0 存档接入扩建流程，已经进入终章的旧存档补齐照片与电台进度，保留既有结局状态。

`campaign.test.mjs` 的 18 项用例检查主线前置、错误操作、物品消耗、两个结局、新旧存档、演出持久化和调查遮挡。`smoke.mjs` 构建全部场景，使用真实碰撞连续走过住户区、B1、两层折返梯、屋顶、东翼、西翼和地下旧区后返回，同时检查平台支撑、楼梯净空、半途返回及怪物上下楼。`traversal.test.mjs` 的 17 项用例覆盖高速薄墙、房间与屋顶封边、异常恢复、四层可达地板探索、相邻墙夹角、平开门和拉门防挤压。`performance.test.mjs` 的 3 项用例检查真实帧时采样、降级冷却和质量恢复；`pursuit.test.mjs` 的 4 项用例检查最后已知位置、脚步声衰减与失去目标。`input-state.test.mjs` 的 4 项用例检查触屏输入清理、调查/暂停叠层和重复谜题操作。`navigation.test.mjs` 与 `navigation-world.test.mjs` 的 16 项用例检查绕障、锁门、换房目标、不可达缓存、计算预算和实际街区追踪路线。`bathroom-fixtures.test.mjs` 的 7 项用例检查真实尺寸、空腔、支撑、排水口、管路连接和碰撞净空；尺寸来源见 [浴室建模依据](docs/references/BATHROOM-FIXTURES.md)。`debug-audit.mjs` 检查墙体穿透、意外边缘坠落与怪物节点支撑；装饰几何相交的报告需要结合实体结构判断。

构建会为脚本和 CSS 写入内容版本，避免静态浏览器缓存旧游戏。

以下为 v4 历史验证记录，并非本轮 4.1 的浏览器验证。浏览器验证脚本与截图在 `output/playwright/`，当前结果见 `output/v4-tests.txt`、`output/v4-audit.txt`、`output/v4-browser-checks.txt`、`output/v4-controller-check.txt` 和 `output/v4-touch-audio-check.txt`，汇总为 `output/v4-verification.json`。46 项浏览器检查在交互点之间使用 QA 定位；调查使用实际视线检测与物件回调，谜题使用真实按钮。另一次浏览器控制器检查连续走完地下旧区 50 个路径点、1,154 个模拟帧，没有定位跳过途中碰撞，也没有触发防坠恢复。四层探索覆盖 47,504 个可达采样点，压力检查覆盖 67,158 步；本次检查未发现穿墙或意外边缘坠落。

触屏布局在桌面浏览器强制触屏模式下检查了 844×390 和 390×844 两种视口，地图缩放、滚动、记录阅读、脚步材质与声音遮挡通过。小屏地图页折叠目标、章节和物品区，保留地图操作；调查记录页仍可查看目标与物品。完整源码包为 `output/echo-apartment-v4.zip`。程序化美术和合成音效已经细化；真人配音、手工角色资产、手机真机性能与实际游玩时长仍未验证或制作。

开发截图可使用 `?autostart=1`、`?pos=1`、`?tp=Z&tpx=X&tpy=Y&yaw=deg`、`?nopost=1`、`?noflash=1`。正常游玩无需这些参数。
